Entry for the [Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc) competition on [make.fun](https://make.fun): one original joke about Monday mornings, at most 200 characters, judged on laughs.

## The joke

> My bed files for custody every Monday morning. My alarm testifies against me. I lose every time.

## How it works

`main.py` is a pure Python standard library program (no third-party
packages). It writes the joke above to `/output/entry.txt` (96 characters,
UTF-8, one joke).

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
